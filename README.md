# 聪儿的研究小屋

聪儿的私人精神医学与心理学阅读小屋。网站以暖白、紫色和陪读小狗为主题，使用静态 GitHub Pages 部署；内容整理在本地完成，不调用在线 LLM。

## 本地预览

在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。

## 已实现

- 首页研究小报、专题列表、关键词搜索、文章详情
- 当前浏览器内的收藏与已读状态（localStorage）
- 手机和桌面自适应、键盘焦点样式
- 原创陪读狗狗插图

## 内容状态

当前版本展示 28 篇正式论文故事：原有 8 篇加本次整理的 20 篇。每篇都可从首页打开，带有故事化正文、研究设计、结果解读、临床边界、术语注释和原文来源。没有公开候选列表或“感兴趣”投票流程。

新增的 20 篇目前依据 PubMed 题录与摘要撰写，文章页明确标出尚未核对期刊全文及补充材料；摘要没有提供的细节不补写。它们是可读的论文故事，但不标为全文审核完成。今后的半月更新仍先在本地检索和评估，再逐篇写作、核对来源与数字；全文无法获取时继续保留摘要基础解读标记。所有正式发布内容在推送前复核。不使用在线 LLM。

## 本次验证

首页共展示 28 篇论文；支持专题筛选、关键词搜索、收藏与已读。收藏/已读保存在当前浏览器。20 篇新增文章均有独立详情页，未核对全文的状态在正文和来源说明中标出。

## 每期标语

`edition.js` 是每期文案配置。每两周发布时一并更新期号、首页标语、两行寄语和狗狗配文；文案根据当期主打主题确定，不随机轮换。敏感临床主题采用克制、尊重的表达，不暗示未经支持的疗效。

## 独立英语学习室

入口 `#english`，内部导航为 Read、Word bank (`#english/words`)、Practice (`#english/practice`)。这些页面始终使用英文界面；仅通过明确的“返回中文研究区”入口回到中文区域。中文站将英语学习室作为独立区域入口，而不是语言切换选项。

`english.js` 存放独立的英文研究博客，内容不与中文版块机械互译。首页以两篇真实研究为主：社交焦虑与孤独/归属感的单组临床研究，以及中国数字心理健康项目的随机试验和大样本真实世界研究。文章讲述研究问题、参与者、设计、结果和边界；英文保持为主，读者可以按段显示中文对照、点击术语看解释，再完成研究理解题。Vocabulary 是文章术语索引，Reading check 检查设计和证据解释，不以背单词作为英语区主内容。来源及审核边界见 [`content/published/2026-10-english-reading-source-review.md`](content/published/2026-10-english-reading-source-review.md)。每半月更新时另选英文阅读主题，不要求和中文版逐篇对应。线上无 LLM 或翻译 API。

已验证：英文研究博客页面、论文原文链接、逐段中译、术语说明与研究设计理解题；每段翻译默认收起。

## 访问控制

当前保留单 token 登录体验。静态登录仅用于私人原型和防普通访客误入，不是强安全边界。收藏与已读仅存浏览器本地，不跨设备同步。

此前的候选兴趣同步原型不再作为网站功能使用。本版本没有候选页面、兴趣投票按钮或兴趣同步请求；研究选题由本地编辑流程筛选，文章发布前经过来源与证据边界核对。
