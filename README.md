# 聪儿的研究小屋

本地初版：公开阅读的精神医学与心理学中文小综述网站。暖白、紫色与陪读小狗主题，无服务端或在线 LLM 调用。

## 本地预览

在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。

## 已实现

- 首页研究小报、专题列表、关键词搜索、文章详情
- 当前浏览器内的收藏与已读状态（localStorage）
- 手机和桌面自适应、键盘焦点样式
- 原创陪读狗狗插图

## 内容状态

当前四篇内容是阅读结构演示，不是实际文献综述。没有编造论文、引用或效果数据。正式内容需要检索、证据表、对照原文复核和发布审核。

后续规划：本地用 Codex 生成和审核综述，每月 1 日、16 日集中发布；未配置自动化、远程仓库或公共部署。正式内容数据应与界面代码拆分，构建阶段落实审核状态门槛。

## 每期标语

`edition.js` 是每期文案配置。每月 1 日、16 日发布内容时，一并更新期号、首页标语、两行寄语和狗狗配文，文案与语气根据当期主打综述主题或共同线索确定，不进行固定或随机的风格轮换。敏感临床主题采用克制、尊重的表达，不暗示未经支持的疗效。同一期内固定，刷新、重新打开或页面切换均不随机更换。当前仍为样刊配置，尚未启用定时发布。

## 独立英语学习室

入口 `#english`，内部导航为 Read、Word bank (`#english/words`)、Practice (`#english/practice`)。这些页面始终使用英文界面；仅通过明确的“返回中文研究区”入口回到中文区域。中文站将英语学习室作为独立区域入口，而不是语言切换选项。

`english.js` 存放独立的英文研究博客，内容不与中文版块机械互译。首页以两篇真实研究为主：社交焦虑与孤独/归属感的单组临床研究，以及中国数字心理健康项目的随机试验和大样本真实世界研究。文章讲述研究问题、参与者、设计、结果和边界；英文保持为主，读者可以按段显示中文对照、点击术语看解释，再完成研究理解题。Vocabulary 是文章术语索引，Reading check 检查设计和证据解释，不以背单词作为英语区主内容。来源及审核边界见 [`content/published/2026-10-english-reading-source-review.md`](content/published/2026-10-english-reading-source-review.md)。每半月更新时另选英文阅读主题，不要求和中文版逐篇对应。线上无 LLM 或翻译 API。

已验证：英文研究博客页面、论文原文链接、逐段中译、术语说明与研究设计理解题；每段翻译默认收起。

## 访问控制

当前提供单 token 登录体验：输入 token 后才显示网站，token 只以 SHA-256 摘要写入 `auth.js`，登录状态使用当前浏览器的 sessionStorage，支持退出。由于这是静态前端，摘要和页面逻辑仍会随网页发送给浏览器；它适合私人原型和防止普通访客误入，不是强安全边界。正式公开部署前应迁移到 Cloudflare Access、Supabase Auth 或同类服务，并把收藏/已读从 localStorage 迁移到受保护的云端数据库。
