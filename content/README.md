# 半月论文综述工作流

目标：每两周发现并评估约 20–30 篇论文，编辑流程内部先筛选，再将适合的论文写成诚实、可追溯、故事化的中文长篇博客。网站展示正式文章，不向读者展示待评估投票池。论文可以是原始研究、系统综述、叙述性综述或指南；数量目标不应降低质量标准。若无法获取全文，文章须明确标注“摘要基础解读”，不声称完成全文核查。

## 每期流程

1. 发现：检索 PubMed、期刊官网、Crossref 和主要精神医学期刊；记录检索式、检索日期和待评估论文。
2. 核实：确认标题、作者、期刊、DOI、发表状态、全文可得性、撤稿或更正信息。
3. 证据表：记录研究问题、设计、样本、对照、主要终点、效应量、置信区间、随访、缺失数据和限制。
4. 故事化：从患者会遇到的临床问题切入，解释研究者为什么提出这个问题、怎样设计研究、结果改变了什么理解。
5. 编辑筛选：每轮发现约 20–30 篇供本地编辑评估，结合临床价值、故事性和全文可得性选题；读者不参与投票。
6. 兴趣提示：在网站“我的书架”点“导出兴趣快照”，将下载的 `sophia-reading-interests-*.json` 留在本机 `~/Downloads`。每期开始运行 `python3 scripts/sync-interests.py`，它会自动导入最新快照到被 Git 忽略的 `content/private/interest-queue.json`。收藏仅提供宽泛的主题优先级；不代表候选论文通过审核，也不保证只检索这些主题。没有快照时，必须报告无法读取偏好，不得推断为没有兴趣。
7. 故事化与综述：对计划发布的每篇优先阅读全文并建立证据表，写成长篇博客；若全文暂时不可得，必须标注摘要基础解读，只陈述摘要明确提供的信息。把多篇研究放在一起比较时，区分一致、矛盾和证据空白。
8. 审核与发布：逐项回到原文核对数字和措辞；摘要看不到的细节不补写；文章进入 `content/published/` 时记录检索截止日、来源和审核日期。发现数量不是质量评级，也不能代替审核。

## 中英文内容分流

中文研究区和 Sophia’s English Studio 不要求同题同步。

- 中文区优先：精神科临床问题、治疗与诊断证据、方法复杂或需要多篇论文综合的主题。篇幅可以更长，重点是证据层级、异质性、适用人群和临床边界。
- 英文区优先：适合英文阅读的心理学资讯、概念解释、研究素养和跨诊断基础知识。英文内容应自然、可读、带有值得学习的专业表达，再配少量对照翻译和词汇练习。
- 同一个主题只有在两边各自有明确价值时才同时出现；英文区不承担中文综述的逐字翻译，中文区也不为了配对而增加文章。
- 英文区的“资讯”可以来自已核实的真实研究，也可以是明确标注的基础概念短读；两者必须在页面上区分，不把概念说明写成最新论文结论。

## 单篇论文导读结构

- 故事开场：一个真实的临床问题（不虚构患者个案的隐私细节）。
- 先说结论：目前证据支持什么，仍不确定什么。
- 研究现场：研究者招募了谁，如何比较，测量了什么。
- 结果转折：哪些发现支持最初假设，哪些结果没有支持。
- 放在一起看：与其他研究的共同点和差异。
- 回到临床：适用人群、效应大小、可迁移性和不能推出的结论。
- 证据账本：检索截止日期、论文状态、关键引用和质量审核记录。

## 论文类型与表达边界

页面明确标注论文类型。原始研究只介绍该研究做了什么、发现了什么；综述论文可以介绍作者如何汇总证据，但不把它改写成我们的系统综述；指南和共识单独标注发布日期、适用范围和证据基础。所有内容都不把单篇论文写成学界共识。

## 门槛

拟发布文章遇到未解决的来源、数据或解释问题就标记为待核实或暂缓；任何文章遇到这类问题都不得作为已审核博客发布。药物剂量、停换药方案和个体化诊疗指令不作为综述结论发布。
