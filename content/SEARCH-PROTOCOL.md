# 候选论文系统检索协议

每两周运行 `python3 scripts/search-candidates.py`，先把 PubMed 的 2025–2026 候选论文追加到 `content/candidates.csv`，再人工筛选。脚本只发现论文，不自动写文章。

筛选顺序：

1. 先排除撤稿、勘误未处理、非同行评审或无法核对来源的记录。
2. 优先系统综述/荟萃分析、临床指南、随机试验和大型纵向研究；小样本机制研究作为补充。
3. 按临床相关性、方法透明度、结果可解释性、全文可得性和与近期证据的增量排序。
4. 每篇候选记录主题、论文类型、DOI、全文状态和暂缓/入选理由。
5. 入选后读取全文，建立证据表，写成论文导读；只有通过逐项核对才移动为已发布内容。

检索来源以 PubMed 和期刊官网为主，必要时用 Crossref 补 DOI。搜索式和日期必须保留，避免每期凭印象选文。


## 故事性与入选门槛

论文进入正式一期前，除了核对研究设计和结果，还要回答：它是否从一个真实的临床困惑出发？结果是否带来可解释的转折？读者读完后是否能因此改变一个判断或提出一个更好的问题？

只有统计数字、没有临床转折，或只是重复已有结论的研究，保留在 candidate 池，不为了凑数量上线。正式文章按“场景—追问—线索—临床回到哪里—仍未解决的问题”组织。
